# 6匹のウサギ・デスクトップペット

macOSのDock上を6匹のウサギが歩き回る試作版です。透明なクリック透過ウィンドウで表示されます。

ウサギは、実ポーズ7フレームのぴょこぴょこ歩行、ニンジンを両前足で持って食べる、立って顔を洗う、眠る動作をランダムに切り替えます。睡眠時はその場で地面を前足で掘り、ウトウトしてから、腹ばいまたは横向きに転がる2種類の寝姿に移ります。

デスクトップ上のウサギをクリックすると、約8秒間の撫でモーションになります。クリックごとに、目を閉じて座ったまま頭を撫でられる姿と、四つん這いでお尻を少し上げて撫でられる姿のどちらかをランダムに選びます。Codex作業中のウサギも一時的に撫でることができ、終了後は作業モーションへ戻ります。

## 起動

Finderで `run.command` をダブルクリックします。初回だけビルドに少し時間がかかります。

終了するには、メニューバーの「🐇」から「6匹のウサギを終了」を選びます。

## うさぎの日記

毎日18時以降、ランダムな1匹が正面を向いて後ろ足で立ち、「日記のじかんだよ！」と呼びかけます。吹き出しをクリックすると、デスクトップ上の小さな入力画面で「今日はどうだった？」に答えられます。1文字以上で保存でき、文字数の上限はありません。メニューバーの「今すぐ日記を書く」からも開けます。

日記は `~/Library/Application Support/RabbitDesktopPet/.diary/YYYY-MM-DD.txt` に1日1ファイルで保存され、ローカルの外には送信しません。7回ごとに「7日間のふりかえり」ウインドウが開き、最近の7件を日付ごとに全文表示します。内容は選択・コピーでき、長い日記はウインドウ内でスクロールできます。

画面右端には月へ行くロケットが表示され、日記を1日書くたびに、うさぎと同じ粒度のドット絵で部品が2段階ずつ追加されます。土台、エンジン、胴体、フィン、窓、先端、アンテナの14種類の独立グラフィックを切り替え、7回で完成・点火します。次の日記で帰還した後、新しいロケットが始まります。

7回目の日記を保存すると、その時点でロケットに最も近い1匹が選ばれます。選ばれたうさぎは宇宙服に着替え、ロケットの左側まで歩いてからヘルメットを抱えて敬礼し、搭乗します。発射中は残りの5匹がその場で正面向きのポーズで手を振り、ロケットが月に届くと通常動作へ戻ります。ロケットは黒い進捗パネルを置いたまま、機首を月へ向けて単独で飛び、搭乗した1匹は翌日まで画面からいなくなります。

次の日記を保存すると、ロケットが機首を地上の進捗パネル側へ反転させ、月からふらつきながら帰還します。デスクトップ右端でドット絵の爆発が起き、中から濃い煤まみれの宇宙服うさぎが現れます。頭を左右にブルブル振るたびに煤が段階的に落ち、元の毛色と通常動作へ戻ります。帰還が終わると、新しいロケットが1/7から始まります。出発中・滞在中・帰還中の状態と搭乗したうさぎは保存され、アプリを再起動しても引き継がれます。

## ロケットのテストモード

メニューバーの「🐇」から「シーケンステストを開始（0/7）」を選ぶと、本番の日記と進捗から独立したテストモードに入ります。「テスト：1日進める」で組み立てを2段階ずつ確認でき、7回目で宇宙飛行士うさぎの歩行・敬礼・搭乗・5匹の見送り・発射・月への飛行まで再生します。月へ到着した後にもう1回進めると、帰還・爆散・黒焦げ・煤払い・通常モーションへの復帰を確認できます。テスト中はうさぎのメッセージ吹き出しを表示しません。

通しで見たい場合は「テスト：全自動再生」を選びます。約35秒で0日目から帰還までを再生します。確認後は「テストモードを終了」を選ぶと、本番のロケット進捗とうさぎの状態に戻ります。テストは日記ファイルや本番の進捗を書き換えません。本番の月旅行中は、表示の衝突を避けるためテストを開始できません。

## LINE・Outlook通知とCodex作業表示

macOSの通知センターに届いたLINE、Microsoft Outlook、Codexの通知を検知すると、ランダムなウサギの上に吹き出しを表示します。吹き出しをクリックすると該当アプリが開き、右側の `×` で閉じられます。操作しない場合は30分後に自動で閉じます。

Codexについてはローカルセッションの作業状態だけを監視します。1件以上のタスクが作業中ならランダムな1匹がノートPC作業モーションになり、すべての作業が終わると通常動作へ戻ります。Codexタスク完了時の吹き出し通知は表示しません。プロンプトや回答本文は読み取りません。

初回起動時は、macOSの「システム設定」→「プライバシーとセキュリティ」→「アクセシビリティ」で `RabbitDesktopPet` を許可してください。アプリは `run.command` と同じフォルダの `RabbitDesktopPet.app` として組み立てられるため、許可一覧にもこの名前で表示されます。自動で追加されない場合は、一覧下の `＋` からこの `RabbitDesktopPet.app` を選べます。メニューバーの「🐇」→「通知アクセスを許可」で許可画面を開き直せます。「テスト通知を表示」で吹き出しだけをテストでき、「通知をすべて閉じる」で待機中の吹き出しもまとめて消せます。

送信者名を表示するには、各アプリとmacOS側で通知プレビューを有効にする必要があります。読み取った通知本文はファイルへ保存しません。

ターミナルから起動する場合：

```sh
swift run RabbitDesktopPet
```
